# docs

- `install/`: every way to install and run noro, each provider, local models, subscription CLIs, agent tools, Docker, scheduled runs and classify. Start at [install/README.md](install/README.md).
- `getting-started.md`: a first run, end to end.
- `schema.md`: the standard schema that platform adapters map to.
- `engine.md`: the Python engine's CLI contract and the rule schema.

Who edits it: maintainers, and contributors fixing a step that didn't work for them. Building and releasing noro is in [DEVELOP.md](../DEVELOP.md).
