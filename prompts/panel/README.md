# Reviewers

Each file here is one reviewer on the panel (`prompts/guides/panel.md`). To add your own:

1. Copy a file here and rename it, for example `analytics-lead.md`. The file name is the id.
2. Keep the three parts: **Voice**, **Checks**, **Always sends back**. 150 words or fewer.
3. Write checks a reader can answer from the draft and the ledger alone. A reviewer can't ask for data the report doesn't hold; it flags the gap for the writer.
4. Save it in `.noro/personas/<id>.md` in the folder you run noro from. The panel step loads it alongside the built-in personas.
5. Add the id to `reviewers` in your settings.
