# bench

`corpus/` holds synthetic reports for judging rewrites by hand. Each case has `original.md` (the report with planted slop), `gold.md` (a good rewrite) and `meta.json` (the slop types, planted traps, numbers and what the gold cuts).

Rules cite these cases in their `source` field. No test runs them yet.

Who edits it: contributors. Every name and number must be invented.
